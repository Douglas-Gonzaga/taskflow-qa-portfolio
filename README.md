# TaskFlow — QA Portfolio

## Sobre o projeto

O TaskFlow é um projeto de gerenciamento de tarefas desenvolvido como projeto de portfólio para aplicação prática de conhecimentos de Quality Assurance (QA).

O projeto simula um produto desenvolvido utilizando uma abordagem ágil, permitindo aplicar atividades de QA desde o entendimento do produto e planejamento da Sprint até a elaboração, execução e documentação dos testes.

## Objetivo

Demonstrar, por meio de um projeto prático, conhecimentos em QA Manual, incluindo:

- Análise de requisitos e regras de negócio
- Planejamento de testes
- Elaboração de cenários e casos de teste
- Aplicação de técnicas de teste
- Execução de testes
- Identificação e registro de defeitos
- Documentação dos resultados
- Organização de evidências de teste
- Acompanhamento de uma Sprint utilizando abordagem ágil

## Atuação em QA

Durante o projeto, foram realizadas atividades relacionadas ao processo de testes, incluindo:

- Análise das funcionalidades e regras de negócio
- Definição do escopo de testes
- Criação de casos de teste
- Execução dos testes
- Registro de resultados
- Identificação de comportamentos inesperados
- Criação de Bug Reports
- Coleta e organização de evidências
- Documentação dos resultados da Sprint

## Principais atividades de teste

A Sprint 1 envolveu a validação de diferentes aspectos do sistema, incluindo:

- Validação de campos obrigatórios
- Validação de regras de entrada
- Validação de limites de dados
- Validação de comportamentos esperados
- Verificação de persistência dos dados
- Identificação de comportamentos divergentes do esperado
- Registro e documentação de defeitos
